## Source selection and global settings

When parameter automation cannot encode a control, record UI label, location, intended value/unit, source page, verified template/live method, and save/reload evidence. Do not replace it with a similar-looking raw key without proving mapping.

Global preferences and patch-specific state are not identical (S2 pp. 312-322). Inspect MPE, quality, compatibility, tuning, envelope/LFO scaling, controller maps, and lock settings when results differ between instances/machines. Scope changes to the user's requested sound/session; preserve unrelated host preferences.

## Formula lookup notes

Manual p. 306 defines `w` in 0..1 and `x` in -1..1 over a cycle, `y/z` across frames, `q` for FFT/harmonic bins, and `in/sel` for existing waveform values. The parser's FFT amplitude representation can differ from a literal amplitude list in the custom-harmonics helper. Translate the intended spectrum using the selected implementation's convention rather than copying exponents mechanically.

## Assets and reload

Use the actual Serum preset/root folders and configured `Tables`/`Samples` paths. Renaming metadata alone may not rename a file/browser entry. Preset browser rescan/reload can be necessary after external writes; verify the exact native artifact, not a similarly named cached preset.
