# Brief and sonic analysis

## Capture the target

Keep the user's original request and a compact interpretation. For a single preset specify only what changes the design; for a production layer also record tempo, musical range, note lengths, neighboring instruments, and mix role.

| Dimension | Questions the design must answer | Useful observation |
|---|---|---|
| Role | Foundation, hook, chord, atmosphere, transition, percussion? | Audibility requirements in its context |
| Pitch | Pitched, inharmonic, noise, fixed pitch, key-tracked? | Fundamental, partial spacing, drift, glide |
| Excitation | Bowed/breathed/plucked/struck/electronic? | Attack spectrum and energy change |
| Amplitude | Immediate/slow onset, held/decaying, abrupt/long release? | Attack, hold, decay, sustain, gate, tail |
| Spectrum | Harmonic density, odd/even balance, resonant bands? | Brightness and spectral envelope over time |
| Motion | Repeated rhythm, independent evolution, random variation? | Rate, shape, depth, trigger, synchronization |
| Stereo | Centered, wide, rotating, diffuse? | Correlation, channel balance, low-band stability |
| Space | Dry, early reflections, echoes, large tail? | Predelay, echo spacing, tail spectrum |
| Performance | Velocity, pressure, mod wheel, glide, MPE? | Which gesture changes which audible property |
| Delivery | Native preset, variants, samples, MIDI, preview? | Files and acceptance evidence required |

Choose defaults when the brief allows: useful register, moderate loudness, named macros, and a test phrase fitting the sound. Document assumptions that could change identity. A genre name alone is context, not a complete synthesis architecture.

## Translate descriptors into causal hypotheses

| User word | First hypotheses | Disambiguate by |
|---|---|---|
| Warm | Reduced upper energy, rounded attack, mild nonlinear harmonics | Darker versus fuller versus saturated |
| Bright | More high harmonics/noise, open filter, pronounced transient | Sustained brightness versus attack only |
| Hollow | Odd harmonics, missing spectral regions, notch/formant structure | Square-like body versus resonant cavity |
| Metallic | Inharmonic partials, FM, frequency shifting, resonant modes | Stable ring versus noisy abrasion |
| Thick | Closely spaced voices, lower mids, saturation, layered spectra | Width versus weight versus density |
| Wide | Unison pan/detune, delays, chorus, different channel information | Required mono compatibility |
| Airy | Soft onset, upper noise, diffuse space | Breath layer versus reverberant distance |
| Punchy | Fast controlled onset, short pitch/brightness burst, clear body | Low-end transient versus loudness |
| Organic | Correlated small variations, changing brightness, expressive gestures | Plausible behavior versus arbitrary randomness |
| Aggressive | Dense harmonics, strong spectral motion, nonlinearities | Preserve pitch and articulation as needed |
| Lo-fi | Band limitation, pitch/time instability, quantization, noise | Specific impairment rather than every defect |
| Glassy | Sparse upper partials, bright short onset, controlled tail | Bell, FM key, or spectral texture |
| Vocal | Moving formant bands with controlled excitation | Vowel morph versus identifiable recorded voice |
| Cinematic | Time-scale, register span, contrast, space, impact | Instrument role rather than a fixed waveform |

Treat these as alternative hypotheses, not one-to-one definitions. For an unfamiliar metaphor, translate it into onset/body/tail, spectral behavior, and motion; offer a coherent interpretation and refine from feedback.

## Acceptance criteria

Write 3-8 task-specific checks such as: stable fundamental on repeated bass notes; upper texture evolves while root remains fixed; pluck decays even on a held note; macros preserve usable pitch and headroom; reference's quarter-note wobble starts in phase; tail fits the gap between phrases. Set numeric tolerances only when meaningful. Avoid imposing a generic mastering loudness target on every sound.
