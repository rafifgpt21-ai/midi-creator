## Mulai di Cubase

1. Atur tempo/meter project, Musical Time Base, dan left locator 1.1.1.0. Gunakan Import to Left Locator untuk impor dari bar 1; Single Part untuk drop.
   Untuk project bertempo tetap sesuai lagu, Ignore Master Track Events on Merge mempertahankan tempo project.
2. Buat satu instrument track per file MIDI; gunakan Serum 2 untuk instrumen melodi.
3. Muat preset pada tabel, lalu drag file dari `MIDI/` ke track tujuan.
4. Pilih kit/sample drum sendiri dan cocokkan pitch pada tabel drum.

## Bentuk lagu

Cantumkan rentang bar dan perkembangan setiap bagian, termasuk ruang release.

## Drum yang cocok

Jelaskan kick, snare/clap, hat, dan percussion yang cocok khusus lagu ini: timbre,
panjang tail, tuning bila perlu, groove, serta ruang yang harus disisakan untuk bass.
Rekomendasi karakter tidak berarti sample sudah dipilih. Cantumkan nama/pitch MIDI
numerik setiap bagian dan status pilihan pengguna. Jelaskan CC7/CC10 jika satu kit
dipakai bersama.

## Instrumen di luar Serum

Jika ada, jelaskan per track: alasan sound membutuhkan instrumen lain, plugin/library
yang diperlukan, cara memuat, rentang nada, artikulasi, keyswitch/drum map, dan pilihan
alternatif. Jika semuanya Serum, tulis bahwa tidak ada instrumen eksternal selain drum.

pemuatan plugin), uji impor Cubase, rendering, dan apakah audio benar-benar didengarkan.
